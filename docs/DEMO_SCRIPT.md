# Five-minute demo

1. Open the public landing page and explain the paper stamp-card problem.
2. Show the merchant dashboard and choose a seeded customer.
3. Open the customer card and review the current stamp history.
4. Show the Mainnet contract and the verified issue transactions.
5. Open the redeem transaction in Stellar Expert.
6. Explain that Freighter signs externally and the application stores no keys.
7. Close with the contract tests and deployment manifest.
