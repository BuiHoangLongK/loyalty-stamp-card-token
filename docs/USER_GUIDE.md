# User guide

## Customer

1. Open the public application and select a customer card.
2. Review the merchant, current stamp balance, and reward threshold.
3. Connect Freighter on Stellar Mainnet when an on-chain action is offered.
4. Inspect the contract address and function before signing.
5. Confirm the resulting transaction in Stellar Expert.

## Merchant

Use the dashboard to find a customer, review recent events, issue eligible
stamps, and redeem only after the threshold is met. Keep the explorer link as
proof for support and reconciliation.

The demo dataset is illustrative. Mainnet actions are separately signed and do
not expose private keys to the application.
