# Accessibility checklist

- Every form control has a visible label.
- Keyboard focus remains visible.
- Status is communicated with text, not color alone.
- Wallet addresses wrap on narrow screens.
- Dialogs return focus to their trigger.
- Loading states use readable text.
- Reduced-motion preferences are respected.
- Screens are checked at 375 px and desktop widths.

Use Playwright and keyboard-only walkthroughs before each public release.
