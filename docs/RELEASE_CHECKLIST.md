# Release checklist

- [ ] Working tree contains only intended changes.
- [ ] Lint, unit tests, contract tests, and production build pass.
- [ ] No secrets or private keys are tracked.
- [ ] Public app and health endpoint respond.
- [ ] Mainnet network and contract ID are visible to the signer.
- [ ] Screenshots match the current UI.
- [ ] Deployment manifest contains verified hashes.
- [ ] README links open without authentication.
- [ ] Rollback commit is known.
